## How to sign

Signing is per person, once — it covers all of Your future Contributions to
the Project.

Open (or comment on) the pull request that carries Your first Contribution and
post the following line:

```
I have read the MOOtation CLA v1.0 and I hereby sign it.
```

Your GitHub account identity and the timestamp of that comment constitute Your
signature. Do not include a postal address, phone number or any other personal
data beyond what GitHub already publishes about Your account.

If You are contributing on behalf of an employer, state that in the same
comment and confirm You have the employer's permission.
